# One Word for Your Wi-Fi: Ghosted

One word describing my Wi-Fi: **Ghosted**.

Home Wi-Fi that vanishes mid-call, mid-game, mid-download — no warning, no goodbye, just gone. Like being ghosted by your own router. Funny at once, true every day, and a word nobody else reaches for first when describing a slow connection.

## Run

```sh
node main.ts
```

This validates `entry.txt` (exactly one word, 1–20 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/entry.txt`).
